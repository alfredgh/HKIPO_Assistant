# HKIPO_Assistant
本项目定位为港股IPO领域的垂直AI助手，聚焦真实业务痛点，以开源形式沉淀行业Know-how，供同行学习、部署、二次开发。
1.1 项目背景
港股IPO业务链条长、参与方多、合规要求严，从承揽期的行业筛选与Pitch Book制作，到承做期的招股书撰写与验证，再到承销期的路演与定价，直至后督期的合规监测——每个环节都依赖大量人工投入。2026年初，OpenClaw等开源AI智能体项目在投研圈的爆火验证了一个趋势：金融从业者迫切需要能将大模型认知能力与业务系统执行能力深度融合的工具，多家券商金工团队已率先探索AI智能体在投研场景的落地。

本项目定位为港股IPO领域的垂直AI助手，聚焦投行真实业务痛点，以开源形式沉淀行业Know-how，供同行学习、部署、二次开发。

1.2 差异化设计
相较于通用AI助手，本项目的核心差异在于：

业务深度：内置港股上市规则、联交所指引信、保荐人尽职调查指引等行业知识，不是"泛金融问答工具"，而是"懂IPO业务的专属助手"

流程闭环：覆盖承揽→承做→承销→后督四阶段，与通用投研工具形成定位差异

合规先行：内嵌敏感信息检测、内幕消息提醒、数据隔离机制，回应金融行业对AI应用的核心关切
