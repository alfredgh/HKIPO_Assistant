# HKIPO_Assistant
1.1 项目背景
港股IPO业务链条长、参与方多、合规要求严，从承揽期的行业筛选与Pitch Book制作，到承做期的招股书撰写与验证，再到承销期的路演与定价，直至后督期的合规监测——每个环节都依赖大量人工投入。2026年初，OpenClaw等开源AI智能体项目在投研圈的爆火验证了一个趋势：金融从业者迫切需要能将大模型认知能力与业务系统执行能力深度融合的工具，多家券商金工团队已率先探索AI智能体在投研场景的落地。

本项目定位为港股IPO领域的垂直AI助手，聚焦投行真实业务痛点，以开源形式沉淀行业Know-how，供同行学习、部署、二次开发。

1.2 差异化设计
相较于通用AI助手，本项目的核心差异在于：

业务深度：内置港股上市规则、联交所指引信、保荐人尽职调查指引等行业知识，不是"泛金融问答工具"，而是"懂IPO业务的专属助手"

流程闭环：覆盖承揽→承做→承销→后督四阶段，与通用投研工具形成定位差异

合规先行：内嵌敏感信息检测、内幕消息提醒、数据隔离机制，回应金融行业对AI应用的核心关切

2.2 关键技术选型
层次	技术选型	选型理由
智能体框架	OpenClaw / LangChain	OpenClaw已验证金融场景执行能力，支持Skills生态
模型层	多模型可插拔（Claude 4.0 / GPT-5 / 千问）	满足不同合规要求和成本考量
向量数据库	ChromaDB（轻量级） / Milvus（生产级）	支持业务知识库本地化存储
部署方式	Docker + 一键部署脚本	降低使用门槛，适配私有化部署需求
安全隔离	容器沙箱 + 敏感词过滤层	满足券商合规要求，参考华创证券提出的"隔离环境部署"建议
三、四阶段功能模块设计
3.1 承揽阶段：智能展业与机会发现
业务场景：MD需要快速识别潜在港股上市标的，制作Pitch Book，准备立项材料。

核心功能：

功能模块	能力描述	AI实现方式
行业热力扫描	自动监测一级市场融资事件、Pre-IPO轮次动态、同行过会进度	Agent定时抓取Crunchbase/IT桔子/港交所披露易，生成周度热点简报
标的智能初筛	根据行业、营收规模、上市前融资轮次等条件筛选潜在标的	RAG检索+规则引擎，输出"关注清单"及初步符合性判断
Pitch Book生成	一键生成行业分析页、可比公司页、时间表建议页	LLM调用模板库+数据填充，输出初稿PPT大纲及关键图表数据
立项材料辅助	协助填写立项报告中的行业分类、可比公司、初步估值区间	从历史项目库中检索相似案例，推荐参数区间
典型指令示例：

"扫描过去3个月国内AI赛道完成B轮及以后融资、营收过亿的公司，生成一份港股上市可行性简报。"

3.2 承做阶段：尽职调查与招股书智能化
业务场景：招股书撰写周期长、验证工作繁琐，涉及多方协作与大量底稿整理。

核心功能：

功能模块	能力描述	AI实现方式
招股书章节生成	根据业务数据自动生成"业务概览""行业分析""风险因素"等章节初稿	基于模板+历史项目的few-shot学习，生成符合联交所格式要求的文本
验证自动化	招股书陈述与底稿文件自动交叉核证	参考Wizpresso Factify方案思路：框选陈述→匹配支持文件→生成验证记录
尽调清单管理	根据项目类型自动生成尽调资料清单，追踪各方提交进度	内置SFC尽职调查指引知识库，动态更新待办
敏感信息检测	自动扫描招股书草稿中的未脱敏数据、关联方遗漏、前后不一致	规则引擎+语义模型双重检测，标注风险点
反馈意见响应	针对联交所反馈意见，检索历史项目的类似问询及回复话术	RAG检索问答库，提供参考回复及支撑底稿位置
关键设计：

验证模块的安全设计：验证过程在隔离沙箱内完成，底稿文件不出本地环境

版本追溯能力：每一次AI生成/修改均记录操作日志，满足底稿审计要求

3.3 承销阶段：路演支持与投资者管理
业务场景：管理层路演、NDR、簿记建档，需要快速响应投资者问题，维护定价模型。

核心功能：

功能模块	能力描述	AI实现方式
投资者Q&A准备	基于招股书生成常见问题库及建议回答要点	LLM提炼招股书关键披露点，匹配历史路演高频问题
可比公司监控	实时追踪可比公司股价、估值倍数、重大公告	Agent接入Bloomberg/Wind API（需授权），异常波动主动预警
定价模型辅助	自动更新估值模型中的市场参数，生成敏感性分析	模板化DCF/可比法模型，参数变化自动刷新
簿记动态简报	汇总订单情况，生成日内简报供内部决策	结构化数据→自然语言简报，定时推送
3.4 后督阶段：合规监测与持续责任
业务场景：上市后需持续监控内幕信息、财务披露、关联交易等合规事项。

核心功能：

功能模块	能力描述	AI实现方式
财务披露日历	自动生成上市公司的年报/中报/业绩预告披露日历	读取联交所披露规则，生成时间轴及提前提醒
关联交易监测	监控上市公司公告，识别潜在须披露的关联交易	NLP解析公告文本，匹配关联方名单，阈值超标预警
持股变动追踪	追踪大股东、董事持股变动，判断是否触发披露义务	接入披露易数据，计算变动比例并提示披露时限
合规规则问答	回答《上市规则》《公司收购守则》等合规问题	RAG检索规则库，引用具体条款回答
